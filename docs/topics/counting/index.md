# Counting and combinations

How many outfits, codes, teams or lottery tickets are there? Counting them one by one is slow and easy to get wrong.
This topic builds, step by step, the clever ways to count without listing, from tidy lists and tree diagrams up to
Pascal's triangle and the binomial theorem.

8 levels, 48 lessons. The ages are only a rough guide for parents and teachers; anyone can start at any level.
