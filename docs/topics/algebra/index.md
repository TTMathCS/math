# Algebra

Algebra is arithmetic with a mystery number in it. You give the unknown a name, write down what you know about it,
and then undo the steps, one at a time, until the mystery is solved. The same moves grow into graphs, curves and
the tools that describe growth.

| Step | Page | You will be able to |
| --- | --- | --- |

| Build | [Equations, functions and straight lines](03-build.md) | Solve any linear equation, use function notation, graph $y = mx + b$ and solve two equations together |
