# Number theory

Number theory is the study of whole numbers: which ones split evenly, which ones never do, and the hidden patterns
in how they fit together. It starts with odd and even and ends with the mathematics that keeps messages secret on
the internet.

8 levels, 48 lessons. The ages are only a rough guide for parents and teachers; anyone can start at any level.
