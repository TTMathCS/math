# Level 6: Conditional probability

*Probability · level 6 of 8 · rough age 13-14 (a guide for parents; anyone can start anywhere)*

New information changes chances. If you know the card is red, the chance it is a heart jumps from a quarter to a half.
This level makes that idea exact with **conditional probability**, uses it to say precisely what "independent" means,
and then puts all the rules to work on some of the most famous puzzles in mathematics: the lottery, the birthday
problem and the Monty Hall game show. It ends with chances that are measured by length and area instead of by
counting.
