# Level 2: Pattern rules

*Patterns and sequences · level 2 of 8 · rough age 7-8 (a guide for parents; anyone can start anywhere)*

In level 1 you continued patterns by looking. In this level you say their rules in words, like "start at 3 and add 2
each time", and use the rules to find numbers far along a pattern. You count up and down by 5s and 10s, find out why
shrinking patterns must stop, discover the stripes and slides hidden in the hundred chart and the addition table, count
toothpick shapes in two ways, and translate one pattern between pictures, tables, number lists and sentences.

| Lesson | You will be able to |
| --- | --- |
| [Pattern rules in words](01-rules-in-words.md) | Write the rule for a number pattern with a start and a step, and explain why two numbers are not enough to know the rule |
| [Growing and shrinking](02-growing-shrinking.md) | Count up by 5s and down by 10s, tell whether a shrinking pattern will land on 0, and where it must stop |
| [The hundred chart](03-hundred-chart.md) | Explain the stripes and slides made by counting by 2, 3, 5, 9, 10 and 11, and add 9 or 11 with one move |
| [Patterns in the addition table](04-addition-table.md) | Find the lines of equal answers, the doubles and the mirror in the addition table, and say why each one is there |
| [Growing shapes](05-growing-shapes.md) | Count the toothpicks in a growing shape in two ways, make a table, and find which shape uses a given number |
| [One pattern, many forms](06-one-pattern-many-forms.md) | Show one pattern as objects, a table, a number list and a sentence, and translate from any form to any other |
