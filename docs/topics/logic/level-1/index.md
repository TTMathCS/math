# Level 1: Sorting and clues

*Logic and puzzles · level 1 of 8 · rough age 5-6 (a guide for parents; anyone can start anywhere)*

Logic starts with sorting and with clues. In this level you sort things by one rule and then by two, find the odd one
out and say **why**, decide whether a sentence is true or false (and find the penguin that breaks "all birds can
fly"), give a robot exact steps and fix its mistakes, and solve riddles by crossing out everything that cannot be the
answer. Every lesson has pictures, things to try at home, and answers to check.

| Lesson | You will be able to |
| --- | --- |
| [Sorting by one rule](01-sorting-one-rule.md) | Sort things into a yes group and a no group, find someone else's rule, and spot a thing in the wrong group |
| [Sorting by two rules](02-sorting-two-rules.md) | Use a sorting mat with four boxes, explain why there are four, and read what an empty box tells you |
| [Which one does not belong?](03-does-not-belong.md) | Find an odd one out with a reason, check the reason against every other thing, and find more than one good answer |
| [True or false](04-true-or-false.md) | Tell true sentences from false ones, break an "all" sentence with one counterexample, and spot sentences that are neither |
| [Robot steps](05-robot-steps.md) | Write exact steps for a robot on a grid, trace a program step by step, and find and fix the bug |
| [Clue riddles](06-clue-riddles.md) | Solve riddles by crossing out what each clue rules out, notice when there are too few clues or none fit, and make your own |
