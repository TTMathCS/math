## Books { #books }

Ten books, one per branch. Each begins at the beginning and ends where mathematicians are still working.

| Book | Starts with | Ends with |
| --- | --- | --- |
| [Algebra](books/algebra/index.md) | Letters for numbers | Galois theory and why there is no formula for the quintic |
| [Geometry](books/geometry/index.md) | Points, lines and angles | Curved space and general relativity |
| [Number theory](books/number-theory/index.md) | Which numbers divide which | The Riemann hypothesis and Fermat's last theorem |
| [Combinatorics](books/combinatorics/index.md) | How many ways? | Ramsey theory and the probabilistic method |
| [Probability](books/probability/index.md) | Coin flips and dice | Brownian motion and measure theory |
| [Statistics](books/statistics/index.md) | Reading data honestly | Causal inference and the replication crisis |
| [Calculus and analysis](books/calculus/index.md) | Speed and area | Lebesgue integration and Fourier series |
| [Linear algebra](books/linear-algebra/index.md) | Arrows and equations | The spectral theorem and the SVD |
| [Logic and foundations](books/logic/index.md) | True and false | Gödel's incompleteness theorems |
| [Topology](books/topology/index.md) | Rubber sheets and bridges | Homology, knots and the Poincaré conjecture |
